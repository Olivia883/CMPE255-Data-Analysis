# CMPE255-Data-Analysis & Machine Learning

## Project Overview

This repository contains coursework for CMPE 255, focusing on exploratory data analysis, preprocessing, unsupervised learning, automated machine learning, and agentic data analysis.

The project is organized into two major parts:

Part 1: Data analysis and machine learning using two different datasets.

Part 2: Agentic exploratory data analysis using an AI-assisted analysis tool.

# Part 1: Dataset Analysis

## Dataset 1 — NYC Airbnb

The NYC Airbnb dataset contains information about New York City rental listings.

The analysis includes data cleaning, exploratory visualizations, feature engineering, K-Means clustering, anomaly detection, and AutoViML regression modeling.

Notebook: Part1/NYC_Airbnb/NYC_Airbnb_EDA.ipynb

Dataset source: https://www.kaggle.com/datasets/dgomonov/new-york-city-airbnb-open-data

## Dataset 2 — Household Power Consumption

The household power consumption dataset contains time-series measurements of electricity usage.

The analysis includes missing-value handling, time-series visualization, feature engineering, K-Means clustering, anomaly detection, and AutoViML regression modeling.

Notebook: Part1/Time_Series/Household_Power_Analysis.ipynb

Dataset source: https://archive.ics.uci.edu/dataset/235/individual+household+electric+power+consumption
